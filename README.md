# OPC UA Data Pipeline & ML Storage

Этот проект представляет собой комплексный пайплайн для сбора, стриминга и хранения промышленных данных с сенсоров (OPC UA) для последующего анализа и обучения моделей машинного обучения (ML).

## 🏗 Технологический стек

* **Data Source:** OPC UA (Промышленные протоколы)
* **Streaming:** [Redpanda](https://redpanda.com/) (Kafka-совместимый брокер сообщений)
* **Processing:** [Arroyo](https://www.arroyo.dev/) (SQL-стриминг данных в реальном времени)
* **Database:** [ClickHouse](https://clickhouse.com/) (Колоночная БД для аналитики)
* **Observability:** [SigNoz](https://signoz.io/) (Мониторинг и трейсинг)
* **Infrastructure:** Docker & Docker Compose
* **ML:** Google Colab (Обучение моделей на собранных данных)

## 📊 Workflow: От датчика до модели

1. Ingestion: Данные считываются с OPC UA серверов.
2. Streaming: Через Redpanda данные поступают в Arroyo для первичной обработки.
3. Storage: Обработанные данные сохраняются в ClickHouse.
4. Analysis: В Google Colab происходит подключение к базе данных, выгрузка датасета и обучение ML-моделей для предиктивной аналитики.

##🛠 Мониторинг

Система интегрирована с SigNoz, что позволяет отслеживать производительность пайплайна, задержки (latency) и возможные ошибки при передаче данных в реальном времени.
